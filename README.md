# DocForge

Просмотрщик и редактор офисных файлов для Android. Работает полностью локально, без интернета и разрешений.

| Формат | Просмотр | Правка текста |
|---|---|---|
| **DOCX** (Word) | да | да |
| **XLSX** (Excel) | да | да (значения и формулы) |
| **PPTX** (PowerPoint) | да | да |
| **ODT / ODS / ODP** (LibreOffice) | да | да |
| **PDF** | да | нет |

Файлы можно открыть кнопкой, из списка недавних, через «Открыть с помощью…» в файловом менеджере или «Поделиться».
Режим правки включается кнопкой с карандашом: нажмите на абзац, ячейку или текст слайда и измените его.
«Сохранить» пишет в исходный файл, а если он доступен только для чтения — предлагает «Сохранить как…».

## Как устроено

- Документ превращается в HTML и показывается в WebView — поэтому работают прокрутка и масштабирование щипком.
  Движки лежат в `app/src/main/java` (чистая Java, без зависимостей — проверяются обычными юнит-тестами на JVM):
  `ooxml/` — DOCX, XLSX, PPTX; `odf/` — ODT, ODS, ODP; `html/` — общий каркас страницы.
- PDF рисуется встроенным в Android `PdfRenderer`, страницы подгружаются по мере прокрутки.
- Правка меняет в XML только нужный текст: оформление нетронутых фрагментов, картинки, стили и остальная структура
  файла сохраняются. Для XLSX после правки удаляется `calcChain` и включается пересчёт при открытии.
- Безопасность: текст документа экранируется, страница работает под строгой Content-Security-Policy,
  WebView не ходит в сеть и не имеет доступа к файлам.

## Ограничения

- Это приближение, а не копия Word/Excel/PowerPoint: нет колонтитулов и сносок, диаграммы и SmartArt показываются
  заглушкой, градиенты и эффекты упрощены, сложные фигуры рисуются прямоугольниками.
- Правится только текст (нельзя добавлять абзацы, строки, картинки и менять оформление). Формулу в Excel можно ввести,
  начав значение с `=`; пересчитает её Excel или LibreOffice при открытии — до этого в приложении видно прежнее значение.
- Старые бинарные форматы `.doc`, `.xls`, `.ppt` не поддерживаются — пересохраните в DOCX/XLSX/PPTX или ODF.
- Файл целиком загружается в память; очень большие документы могут не открыться на слабых устройствах.
