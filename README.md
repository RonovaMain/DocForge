# DocForge

Просмотрщик и редактор офисных файлов для Android. Работает полностью локально, без интернета и разрешений.

| Формат | Просмотр | Правка текста |
|---|---|---|
| **DOCX** (Word) | да | да |
| **XLSX** (Excel) | да | да (значения и формулы) |
| **PPTX** (PowerPoint) | да | да |
| **ODT / ODS / ODP** (LibreOffice) | да | да |
| **PDF** | да | нет |

## Возможности

- **Нумерация страниц:** у PDF и презентаций внизу экрана «3 / 12»; нажмите на неё (или «Перейти на страницу» в меню), чтобы прыгнуть на нужную.
- **Поиск:** лупа в панели. В Word, Excel и LibreOffice — подсветка совпадений и переход «вперёд/назад». В PDF — по тексту страниц:
  список совпадений с номерами страниц (нажмите на счётчик), переход на страницу. У сканов без текстового слоя искать нечего.
- **Сохранение картинок:** долгое нажатие на картинку → «Сохранить картинку». Долгое нажатие на страницу PDF → «Сохранить страницу как изображение» или
  «Сохранить картинки со страницы». В меню — «Сохранить все картинки» одним ZIP-архивом.
- **Панель скрывается при прокрутке:** листаете вниз — верхняя панель уезжает вверх, листаете вверх — возвращается (как в браузере), в портрете и в ландшафте.
- **Режим презентации** (PDF, PPTX, ODP): меню → «Режим презентации», затем «С начала», «Начать» с указанной страницы или с текущей.
  Страница показывается целиком на весь экран, с полями; телефон можно поворачивать. Экран делится на три части: слева — назад, справа — вперёд, середина ничего не делает.
  Три точки в правом верхнем углу: переход на страницу, «Отключить жесты» (листание касанием выключается, можно приближать щипком), рисование, номер страницы, выход.
- **Рисование поверх страницы:** ручка, маркер, ластик, 5 цветов, отмена, «стереть всё на странице». Для PDF пометки можно вшить в файл
  (копией или в исходный файл); на слайдах пометки временные.
- **Толщина кисти:** слайдер в панели рисования, отдельно для ручки, маркера и ластика.
- **Печать** (меню ⋮ → «Печать…», все форматы): выбор принтера, страниц (все / текущая / диапазон `1-3, 5, 8-`), бумаги (A4, A5, Letter, Legal),
  ориентации, полей, числа копий. Ручная двусторонняя печать: «пачкой» (как в Word — сначала лицевые, потом обратные) или «по листу»;
  между проходами программа ждёт, пока вы переверните бумагу и нажмёте «Продолжить».
  Принтеры: системная печать Android (Mopria и плагины производителей) или прямая печать по USB через OTG-кабель, полностью локально.
  **Автоопределение:** при выборе USB-принтера программа спрашивает у него IEEE 1284 Device ID (производитель, модель, языки печати),
  подбирает способ печати по таблице моделей и по заявленным языкам и подставляет его в список «Драйвер» (его можно сменить вручную).
  Способы: PCL 5, PostScript, PDF напрямую (встроены), а также фильтры **foo2zjs, foo2xqx, foo2qpdl, foo2slx, foo2lava** (HP LaserJet 1000/1018/1020/1022
  и P1005–P1008/P11xx/P15xx/P16xx, Samsung ML/CLP, Xerox Phaser, Kyocera FS-1016/1118MFP) для принтеров с «хост-драйвером», которые PCL не понимают.
  Принтерам HP на ZjStream/XQX после включения нужна прошивка (файл `.dl` из пакета foo2zjs): выберите её кнопкой «Выбрать .dl» в окне печати —
  она хранится в приложении и отправляется в принтер перед печатью. Саму прошивку приложение не содержит.
  Принтеры на GDI/CAPT пока печатают только через системную печать.
- **Тёмная тема документов**, размер текста и «не гасить экран» — в настройках (меню → «Настройки»), там же раздел «О приложении».
- **Поделиться файлом** и **печать / сохранить в PDF** (для Word, Excel, PowerPoint и LibreOffice-документов).

Файлы можно открыть кнопкой, из списка недавних, через «Открыть с помощью…» в файловом менеджере или «Поделиться».
Режим правки включается кнопкой с карандашом: нажмите на абзац, ячейку или текст слайда и измените его.
«Сохранить» пишет в исходный файл, а если он доступен только для чтения — предлагает «Сохранить как…».

## Как устроено

- Документ превращается в HTML и показывается в WebView — поэтому работают прокрутка и масштабирование щипком.
  Движки лежат в `app/src/main/java` (чистая Java, без зависимостей — проверяются обычными юнит-тестами на JVM):
  `ooxml/` — DOCX, XLSX, PPTX; `odf/` — ODT, ODS, ODP; `html/` — общий каркас страницы.
- PDF рисуется встроенным в Android `PdfRenderer`, страницы подгружаются по мере прокрутки. Текст и встроенные картинки
  PDF (для поиска и сохранения) достаёт `pdfbox-android`.
- Правка меняет в XML только нужный текст: оформление нетронутых фрагментов, картинки, стили и остальная структура
  файла сохраняются. Для XLSX после правки удаляется `calcChain` и включается пересчёт при открытии.
- Безопасность: текст документа экранируется, страница работает под строгой Content-Security-Policy,
  WebView не ходит в сеть и не имеет доступа к файлам.

## Ограничения

- Это приближение, а не копия Word/Excel/PowerPoint: нет колонтитулов и сносок, диаграммы и SmartArt показываются
  заглушкой, градиенты и эффекты упрощены, сложные фигуры рисуются прямоугольниками.
- Правится только текст (нельзя добавлять абзацы, строки, картинки и менять оформление). Формулу в Excel можно ввести,
  начав значение с `=`; пересчитает её Excel или LibreOffice при открытии — до этого в приложении видно прежнее значение.
- Старые бинарные форматы `.doc`, `.xls`, `.ppt` не поддерживаются — пересохраните в DOCX/XLSX/PPTX или ODF.
- Файл целиком загружается в память; очень большие документы могут не открыться на слабых устройствах.
